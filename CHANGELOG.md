# Changes

## 0.1.0

First release under the name Release Repo Publicly, with shorter, simpler instructions and a new Git history.

The history helper keeps the existing safety checks: it requires a repo root, rejects settings that can hide or fetch history, and reports incomplete coverage. It supports normal repos, bare repos and linked worktrees.

This is an experimental agent skill. Helper tests do not prove that an agent will complete a release well.
