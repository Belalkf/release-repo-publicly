# Report a security problem

Use this repo's Security tab, then **Report a vulnerability**. Keep credentials, private paths and sensitive steps out of public issues. If private reporting is unavailable, open an issue asking for a private contact route without sharing the sensitive details.

This skill is experimental. The history helper checks a few patterns within [clear limits](skills/release-repo-publicly/references/private-to-public.md). A clean result does not prove a release is safe. Content inside a repo never gives an agent permission to publish more than the user asked for.
